# 1장. 빅데이터의 이해
## 1. 빅데이터 정의 및 특성
### 더그 래니의 3V ⭐⭐⭐ 🔖반드시 암기
- **Volume(크기, 양)** : 데이터 양의 증가 (예) 구글 번역 서비스
- **Variety(다양성)** : 데이터 유형 증가
- **Velocity(속도)** : 데이터의 수집 및 처리 속도 증가

### 빅데이터의 새로운 특징 4V ⭐⭐⭐
- 기존 3V에 Veracity(정확성) 또는 Value(가치) 등의 속성을 더해 4V로 설명하기도 한다.
  - Value(가치): 가치 발견 중요
  - Veracity(정확성): 예측 분석 결과에 대한 신뢰성, 유효성 중요
- 또는 Visualization(시각화), Variability(가변성), Veracity(신뢰성, 고품질 데이터), Volatility(휘발성, 데이터가 의미있는 기간)을 추가하기도 한다.


## 2. 빅데이터의 출현 배경 및 영향
### (1) 빅데이터 출현 배경 🔖단편적인 부분을 물어보므로 문제 보고 판단해도 됨
- 데이터의 양적 증가
- 산업계 및 학계의 변화
- 데이터 관련 기술의 발전
  - 디지털화의 급진전, 저장 기술의 발전과 가격 하락, 인터넷의 발전과 모바일 시대 돌입, **클라우드 컴퓨팅 보편화** 등이 매우 밀접하다.
  - 특히 **클라우드 컴퓨팅은 빅데이터 분석에 경제성을 제공해준 대표적인 기술로, 빅데이터의 처리 비용을 획기적으로 낮추었다.**
  - 저장매체 가격 하락, 하둡을 활용한 분산 컴퓨팅, 비정형 데이터 확산

### (2) 빅데이터의 기능과 변화  *크게 어렵지는 않을 것임
#### 빅데이터의 기능⭐⭐⭐
- 빅데이터는 **"산업혁명의 석탄, 철", "21세기 원유", "렌즈", "플랫폼"** 등으로 비유됨

#### 빅데이터가 만들어내는 변화⭐⭐⭐ 🔖시험에 잘 나옴!! 전후양상
- 표본조사 → **전**수조사
  - IoT, 클라우드 기술의 발전으로 데이터 처리 비용이 감소하게 되면서 데이터 활용 방법이 표본조사에서 전수조사로 변화했다.
- 사전 처리 → 사**후** 처리
  - 데이터를 사전 처리하지  않고, 가능한 많은 데이터를 모으고 데이터를 다양한 방식으로 조합하여 숨은 인사이트를 발굴한다.
- 질 → **양**
  - 수집 데이터의  양이 증가할수록 분석의 정확도가 높아져 양질의 분석 결과 산출에 긍정적인 영향을 주었다.
- 인과관계 → **상**관관계
  - 특정한 인과관계가 중요시되던 과거와 달리, 데이터의 양이 급격하게 늘어나면서 상관관계를 통해 현상의 발생 가능성이 포착되고 그에 상응하는 행동을 추천하는 등 상관관계를 통한 인사이트 도출이 점점 확산되고 있다.


# 2장. 데이터의 가치와 미래
## 1. 빅데이터의 가치와 영향
### (1) 빅데이터의 가치⭐ 
- 빅데이터의 가치는 결국 어떤 인사이트를 발굴해 어떻게 활용할 것인지에 달렸다.
- 빅데이터 가치 산정은 데이터 활용 방식, 가치 창출 방식, 분석 기술의 발전이라는 세 가지의 이유로 쉽지 않다.
  - 데이터 활용 방식: 빅데이터의 재사용이나 재조합, 다복적용 데이터 개발 등이 일반화되면서 특정 데이터를 누가, 언제, 어떻게, 어디서 활용하는지 알 수 없게 되었기 때문에 가치 산정이 어렵다.
  - 가치 창출 방식: 빅데이터는 기존에 없던 새로운 가치를 창출함에 따라 그 가치를 산정하기 어렵다.
  - 분석 기술의 발전: 데이터 분석 기술의 발전으로 가치 있는 데이터와 가치 없는 데이터의 경계를 나누기 어려워졌다.

## 2. 빅데이터와 비즈니스 모델
### (1) 미래의 빅데이터 활용에 필요한 3요소 ⭐ 🔖인자기
- 인력: 데이터 사이언티스트, 알고리즈미스트
- 자원(데이터): 모든 것의 데이터화
- 기술: 진화하는 알고리즘, 인공지능

### (2) 7가지 빅데이터 활용 기본 테크닉⭐⭐⭐ 🔖방법과 예시 잘 알아두기
- ① **연관 규칙 학습(=연관 분석, 장바구니 분석, Association rule learning)**
  - 어떤 변인 간에 주목할 만한 상관 관계가 있는지를 찾아내는 방법
  - (예) A를 구매한 사람이 B를 더 많이 사는가? / 이것을 구매한 사람들이 많이 구매한 물품은? / 장바구니 분석 / 상품 추천 
- ② **유형분석(=분류분석, Classification tree analysis)**
  - 새로운 사건이 속할 범주를 찾아내는 방법, '이 사용자가 어떤 특성을 가진 집단에 속하는가?' 같은 문제를 해결하는 방법
  - (예) 문서를 어떻게 문류할 것인가? / 조직을 어떻게 여러 그룹으로 나눌 것인가? / 온라인 수강생들의 특성을 반영해 어떻게 분류할 것인가?
- ③ **유전 알고리즘(Genetic algorithms)**⭐
  - 최적화가 필요한 무제의 해결채을 자연 선택, 돌연변이 등과 같은 메커니즘을 통해 점진적으로 진화시켜 나가는 방법
  - (예) 최적화된 택배 차량 배치⭐ / 최고의 시청률을 내기 위한 방송 프로그램 배치⭐ / 응급실에서의 효율적 의사 배치
- ④ **기계학습(=머신러닝, Machine learning)**
  - 컴퓨터가 데이터로부터 규칙을 찾고 이러한 규칙을 활용해 '예측'하는 데 초점을 둔 방법
  - (예) 유튜브 및 넷플릭스의 미디어 추천 시스템⭐ / 스팸 메일 필터링 / 질병 진단 예측
- ⑤ **회귀분석(Regression analysis)**
  - 독립변수(원일)를 조작하면서 종속변수(결과)가 어떻게 변하는지를 보며 수치형으로 이루어진 두 변인의 관계를 파악하는 방법
  - (예) 구매자의 나이가  구매 차량의 타입에 어떤 영향을 미치는가? / 사용자의 만족도가 충성도에 **어떤 영향**을 미치는가? / 이웃들과 그 규모가 집값에 어떤 영향을 미치는가? / 상품 가격은 애출에 어떤 영향을 치미는가? / 수도권에 가까울수록 부동산 가격이 비싸지는 이유
- ⑥ **감정분석(=텍스트 마이닝, Sentiment analysis)**
  - 특정 주제에 대해 말하거나 글을 쓴 사람의 감정을 분석하는 방법
  - 비정형 데이터 마이닝의 대표적인 기법 중 하나로, 텍스트 파일로부터 단어를 추철된 단어의 긍정, 부정을 선별해 글을 쓴 사람의 감정을 분석하는 방법 => NLP(자연어처리)
  - (예) 호텔에서 고객의 후기를 분석해 고객의 니즈를 찾아낸다. / 제품의 사용기에 나타난 고객의 감정 / 새로운 환불 정책에 대한 고객의 평가 분석
- ⑦ **소셜 네트워크 분석(SNA, Social network analysis)**
  - 사회 관계망 분석으로도 불리며, SNS 같은 온라인 공간에서 유저 사이의 팔로워, 팔로잉 관계를 분석해 영향력이 있는 사람을 찾아내 기업의 효율적 마케팅이나 범죄 수사에서 공범을 찾는 등의 다양한 분야에서 활용 가능
  - 오피니언 리더, 즉 영향력 있는 사람을 찾아내, 고객 간 소셜 관계를 파악할 수 있다.
  - (예) 도시계획 및 지리학 분야에서 도시공간분석에 이용 / 특정인과 다른 사람이 몇 촌 정도의 관계인가? / 이 사람이 어느 정도 영향력 있는 인플루언서인가?

## 3. 빅데이터의 위기 요인과 통제 방안
### (1) 위기요인⭐⭐⭐
- 사생활 침해
  - 구글의 사용자 행동 패턴 예측
  - (예) SNS에 여행 게시글을 올린 사용자를 대상으로 한 빈집털이 발생
- 책임 원칙 훼손
  - 범죄 발생 이전에 체포
  - (예) 신용카드 발급 여부 판단에 있어 불이익 발생
- 데이터 오용
  - 비행기 탑승 금지자 목록에 상원 의원이 포함
  - (예) 적군의 사망자 수로 전쟁의 승리를 예측하는 오류

### (2) 통제방안⭐⭐⭐
- 사생활 침해 -> '동의'에서 **'책임'으로**
  - 개인정보 제공자의 '동의'를 통해 해결하기 보다 개인정보 사용자의 책임으로 해결한다.
- 책임 원칙 훼손 -> **결과 기반 책임 원칙 고수**
  - 특정인의 '성향'에 따라 처벌하는 것이 아닌 '행동 결과'를 보고 처벌
  - 범죄를 저지를 것이라 예상 되더라도 현 시점에는 아무런 범죄가 발생하지 않았으므로 어떠한 조치도 불가
- 데이터 오용 -> 알고리즘 접근 허용
  - 데이터가 어떻게 사용되어 어떠한 이유로 피해자가 발생했는지 알고리즘을 살펴봄으로써 피해자를 구제할 수 있다.(결과가 항상 옳지만은 않음)
  - 최근에는 알고리즘을 이해하고 해석함을써 사전에 피해자를 방지하고 피해자를 구제하는 전문 인력인 알고리즈미스트(Algorithmist)가 부상함.

### (*) 개인정보 비식별 기술⭐
- 데이터 마스킹: 데이터의 기존형식 유지한 채 식별할 수 없는 임의의 값(혹은 기호)으로 대체
  - (예) 플레이 데이터 -> *** 데이터
- 가명 처리: 데이터의 값을 다른 값으로 변경
  - (예) 홍길동 -> 임꺽정
- 총계 처리: 각각의  데이터 값이 아닌 전체 데이터에 대한 총합 또는 평균으로 데이터를 보여줌
  - (예) 70점 80점 90점 -> 평균 80점
- 데이터 값 삭제: 데이터 값의  일부를 삭제
  - (예) 서울시 서초구 -> 서울시
- 데이터 범주화: 데이터의 값을 범주화 해 특정 값이 아닌 범위를 제공
  - (예) 수학 80점 -> 수학 70-90점


# 3장. 가치 창조를 위한 데이터 사이언스와 전략 인사이트
## 1. 빅데이터 분석과 전략 인사이트
- 데이터는 크기가 아니라 데이터로부터 어떤시각과 인사이트(Insight, 통찰)을 얻을 수 있느냐의 문제
- 그러므로 집중과 선택, 넓은 시야, 전략적 인사이트가 중요하다.

## 2. 전략 인사이트 도출을 위해 필요한 역량
### (1) 데이터 사이언스
- 데이터 사이언스란 데이터로부터 의미 있는 정보를 추출해내는 학문
- 통계학이 정형화된 실험 데이터를 분석 대상으로 하는 것에 비해, 데이터 사이언스는 정형 또는 비정형을 막론하고 다양한 유형의 데이터를 대상으로 함.(총제적 접근법)

### (2) 데이터 사이언스 구성 요소⭐⭐ 🔖AI비
- Analytics: 수학, 확률 모델 머신 러닝, 분석학, 패턴 익식과 학습, 불확실성 모델링 등
- IT(Data Management): 시그널 프로세실, 프로그래밍,  데이터 엔지니어링, 데이터 웨어하우징, 고성능 컴퓨팅 등(이과적)
- 비즈니스 분석: 커뮤니케이션, 프레젠테이션, 스토리텔링, 시각화 등(문과적)

### (3) 데이터 사이언티스트에 요구되는 역량⭐⭐⭐ 🔖숙지하고 있어야함.
- 하드 스킬(Hard Skill) -> 이과적
  - 빅데이터에 대한 이론적 지식: 관련 기법에 대한 이해와 방법론 습득
  - 분석 기술에 대한 숙련: 최적의 분석 설계 및 노하우 축적
- 소프트 스킬(Soft Skill) -> 문과적
  - 통찰력 있는 분석: 창의적 사고, 호기심, 놀리적 비판
  - 설득력 있는 전달: 스토리텔링, 시각화
  - 다분야 간 협력: 커뮤니케이션
 
## 3. 빅데이터 그리고 데이터 사이언스의 미래
### (1) 가치 패러다임의 변화⭐ 🔖Digital C A 메라
- [과거(Digitalization) -> 현재(Connection) -> 미래(Agency)]
- 디지털화(Digitalization)
  - 아날로그의 세상을 어떻게 효과적으로 **디지털화하는가**가 이 시대의 가치를 창출해 내는 원천
  - (예) 운영체제, 워드/파워포인트 같은 오피스 프로그램
- 연결(Connection)
  - 디지털화된 정보와 대상들이 **서로 연결**되어 이 연결이 얼마나 효과적으로 효율적으로 제공되느냐가 이 시대의 성패를 가름
  - (예) 구글의 검색 알고리즘, 네이버의 콘텐츠
- 에이전시(Agency)
  - 사물인터넷(IoT)의 성숙과 함께 연결이 증가하고 복잡해짐, 복잡한 연결을 얼마나 효과적으로 믿을 만하게 **관리하는가**가 이슈
  - 데이터 사이언스의 역량에 따라 좌우
