# 1장. 분석 기획과 분석 방법론
## 1. 분석 기획
### (1) 분석 기획의 정의와 특징
#### 분석 대상과 그 방법에 따른 4가지 분석 주제⭐⭐⭐
- 분석 대상이 무엇인지 앎 / 분석 방법 앎 -> 최적화(Optimization)
- 분석 대상이 무엇인지 앎 / 분석 방법 모름 -> 솔루션(Solution)
- 분석 대상이 무엇인지 모름 / 분석 방법 앎 -> 통찰(Insight)
- 분석 대상이 무엇인지 모름 / 분석 방법 모름 -> 발견(Discovery)
(*이해위한 표 추가 예정)

### (2) 목표 시점별 분석 기획 ⭐⭐
- **과제 단위(당면한 분석 주제 해결)**: **빠르게 해결**하는 목적
- **마스터플랜 단위(지속적 분석 문화 내재화)**: **지속적으로 문제를 분석**해 해결하는 것이 목적

### (3) 분석 기획 시 고려사항 ⭐⭐⭐
- **가용 데이터 고려**: 분석의 기본인 **데이터가 확보될 수 있는지**
- 적절한 활용 방안과 **유스케이스의 탐색**: **기존에 잘 구현되어 활용되고 있는** 유사 시나리오 및 솔루션을 **최대한 활용**하는 것이 중요
- 장애요소에 대한 **사전 계획 수립**: 분석 수행시 발생 가능한 장애 요소에 대한 사전 계획 수립 필요
- 조직 역량 내제화

## 2. 분석 방법론 개요
### (1) 분석 방법론 이란?
- 주어진 과제를 해결하기 위해 조직이 어떠한 절차로 작업을 수행해 나갈 것인지 일련의 절차를 정의한 것

### (2) 방법론 구성 요소 ⭐
- **절차**: 작업을 수행하기 위한 과정
- **방법**: 해당 절차를 수행하기 위한 방법 (예) 전문가에 자문을 구하거나 고객의 요구사항 파악을 위한 대면조사 등
- **도구와 기법**: 작업을 수행하는 데 필요한 것, 분석 수행 언어, 프로그램, 분석환경 등의 도구와 기법
- **템플릿**: 어떤 작업을 수행하기 위해 문서를 작성할 때 참고할 수 있는 일종의 양식
- **산출물**: 해당 작업이 종료된 이후 작성되는 문서 또는 프로그램
