## 알고리즘의 복잡도를 계산하는 방법
1. **반복 대치**: 점화식을 더 작은 변수에 대한 점화식으로 대치하는 작업을 반복하면서 경계조건에 이를 때까지 전개하는 방법
2. **추정 후 증명**: 점화식의 점근적 복잡도를 추정한 후 이를 수학적 귀납법의 원리를 이용해 증명하는 방법
3. **마스터 정리**: 특정한 모양으로 표현되는 점화식의 복잡도를 복잡한 계산이나 증명없이 바로 알 수 있는 편리한 방법

# 1. 점화식
- 🔖어떤 함수를 자신과 똑같은 함수를 이용해 나타내는 것
- (예) n!의 점화식: f(n) = n * f(n-1), 피보나치 수열의 점화식: f(n) = f(n-1)+f(n-2)
- 점화식은 **자기호출을 사용하는 함수(재귀 함수)의 복잡도를 구하는데 유용**하다.
- 입력의 크기가 n인 함수의 수행 시간이 T(n)이면, T(n)은 크기가 반인 두 개의 문제를 해결하는 시간과 이들을 병합하는 후처리 시간으로 구성된다.
- 즉, T(n)은 자신보다 크기가 반인 변수로 표현된 함수를 포함하는 점화식이다.

# 2. 점화식의 점근적 분석 방법
## 반복 대치
- T(n)을 T(n-1)로 대치하고, T(n-1)을 T(n-2)로 대치하고, 계속해서 T(n-2), T(n-1), ..., T(1)까지 **반복해서 대치해가는 방식을 사용해 점근적 복잡도를 구하는 방법**

## 추정 후 증명
- **식의 모양을 보고 점근적 복잡도를 추정한 다음, 그것이 옳음을 귀납적으로 증명하는 방법**

## 마스터 정리
- **특정한 모양을 가진 재귀식에서 바로 결과를 알 수 있는 유용한 정리**
