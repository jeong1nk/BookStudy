## 4-1 단계별 프롬포트와 할 일 관리 앱

### 단계별 프롬포트 전략

- PRD를 기반으로 프로젝트를 여러 단계로 나누어,  각 단계마다 AI에게 구체적인목표를 제시하는 프롬포트 설계 방식
1. PRD 작성: 클로드 우베에서 기획/설계
2. 프롬포트 변환: 단계별로 분할
3. 순차 실행: 클로드 코드에서 구현
4. 결과 확인: 각 단계 검증
- 웹에서 기획/ 설계 후 코드에서 구현하는 것이 효율적인 워크플로

### 할 일 관리 앱 5단계 구현

- 위 프롬포트 전략을 적용해 할 일 관리 앱을 만드는 5단계를 구현해보자.
1. 기본 구조: 할 일 추가, 완료 체크, 삭제 기능
2. 카테고리: 업무/개인/공부, UI 개선, 분류 기능
3. 대시보드: 진행률 표시, 머니 차트, 수정 기능
4. 고급 기능: 다크 모드, 일괄 삭제, 단축키
5. 최적화: 정렬 옵션, 내보내기, 가져오기
- 각 단계마다 결과를 확인 해 점진적으로 기능을 추가한다.

### 클로드 코드 명령어

- **/status**: 현재 세션의 상태를 확인, 사용중인 모델이나 토큰 사용량 등도 확인 가능
- **/model**: 현재 사용중인 AI모델 확인
- **/help:** 사용 가능한 모든 명령어 확인

## 4-2 작업 재개와 효율성 높이기

### claude —resume(시작할때), /resume (시작 후)

- 이전 대화 내용을 불러와 마지막 상태 그대로 이어 작업할 수 있게 함
- 몇 분 전으로 이동할지도 선택할 수도 있음

### **Ctrl+C 두 번, /exit**

- 작업이 끝나고 처음 프롬포트 상태로 돌아옴(빠져나감)

### claude —continue, claude -c(시작할때)

- 마지막에 작업했던 상태로 돌아감

### /context

- 컨택스트 사용량 시각화

### 컨택스트 압축하기

- **/compact**: 대화 기록을 요약해 컨택스트 공간 확보(Ctrl+O로 요약 확인)
    - /compact —level 1: 불필요한 공백과 중복 제거
    - /compact —level 2: 변수명 단축, 구조 단순화
    - /compact —level 3: 핵심 로직만 유지, 최대압축
- 작업 단위가 끝날 때마다 /compact를 실행 권장하며, 압축 후에도 CLAUDE.md와 프로젝트 파일은 유지됨

## 4-3 프로젝트 개선과 작업 관리

### 이미지로 UI 개선하기(멀티모달)

- 클로드는 **멀티모달AI**로 텍스트뿐만 아니라 이미지로도 요구사항을 전달할 수 있다.
1. 화면 캡쳐: 윈도우 캡처 도구로 현지 UI 스크린샷
2. 이미지 전달: 이미지 파일을 터미널에 드래그앤 드롭
3. 요청 입력: “이 디자인을 PC용 풀 스크린으로 바꿔줘”
- 이미지 입력 시 [Image #1]과 같이 표시됨

### @

- 이미 생성된 코드나 폴더를 빠르게 확인가능
- 원하는 파일을 검색 후 화살표 키로 선택해서 추가적인 지시도 가능

### /config

- 이 프로그램과 시스템의 설정이 한눈에 보여짐
- 규칙을 정할 수도 있음
- esc로 빠져나옴

### /doctor

- 현재 실행 중인 클로드 코드가 정상적으로 실행되고 있는지 점검하는 명령어
- 이상이 없다면 enter를 눌러 진단 마치기

### /export

- 대화 내보내기
- 현재 작중인 프로젝트를 하나의 결과물로 내보냄
- 클립보드 또는 파일로 저장 가능
