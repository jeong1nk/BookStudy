## 🔖핵심 키워드
- **클로드 코드**: 터미널에서 AI와 대화하며 파일 생성/수정하는 도구
- **Node.js/Git**: 실행 환경(Node.js)과 버전 관리 도구(Git)
- **MNIST**: 손글씨 숫자 7만 장의 표준 데이터 세트
- **배치 파일**: 윈도우 명령어를모아 실행하는 .bat 파일
- **CLAUDE.md**: 프로젝트 생성 파일, 시작 시 자동 로드
- **/init**: [CLAUDE.md](http://CLAUDE.md) 자동 생성 초기화 명령dj
- **# 키**: CLAUDE.md에 규칙을 빠르게 추가하는 단툭키
- **계층적 구조**: 루트에 공통, 하위에 특화 규칙 분리 관리


## 03-1 클로드 코드 설치하기
### 실습 환경 준비하기
- 필요한 도구 두 가지
1. **Node.js**: 자바스크립트 실행 환경, 클로드 코드가 동작할 기반 제공
2. **Git**: 버전 관리 도구, 소스 코드 변경 이력 기록 및 관리
→ Node.js가 클로드 코드를 실행할 엔진이라면, 깃은 프로젝트를 관리할 도구 상자

- 터미널(명령 프롬포트) 실행하기

```jsx
cmd
```

→ 클로드 코드 설치와 Node.js, Git의 실행은 터미널에서 가능하다.

- 클로드 코드 설치

```jsx
npm install -g @anthropic-ai/claude-code
```

- 이후 모드 선택 및 로그인(플랜 또는 API)
→ 플랜은 해당 플랜을 구매 후 사용 가능하며, API는 사용량에 따라 금액 부과(기본5달러)

## 03-3 CLAUDE.md로 프로그램 확장하기
### [CLAUDE.md](http://CLAUDE.md) 파일의 역할
- 프로젝트의 구조, 코딩 스타일, 핵심 명령어 등을 문서화한 설정 파일. 클로드 코드 실행 시 자동으로 읽어들임
- 불필요한 설명은 토큰을 낭비하므로, 간결하고 명확하게 작성해야 한다.
- 맥락 유지: 세션이 끊어져도 프로젝트 맥락 복원
- 규칙 저장: 코딩 스타일과 프로젝트 규칙 기록
- 자동 로드: 클로드 코드 시작 시 자동으로 읽어들임

### [CLAUDE.md](http://CLAUDE.md) 파일 설정하기
- 🔖클로드 코드 내에서 `/`를 누르면 기본적으로 쓸 수 있는 명령어를 확인할 수 있다.

```jsx
*클로드 코드 실행 후*

/init
```

- [CLAUDE.md](http://CLAUDE.md) 파일 내용
    - 프로젝트 개요
    - 실행 방법 (명령줄 및 배치 파일)
    - 필요한 의존성 패키지
    - 신경망 및 GUI 애플리케이션의 아키텍처 설명
    - 데이터 파일 목록

```
*#을 사용하면 해당 내용을 자동으로 [CLAUDE.md](http://CLAUDE.md) 파일에 저장함*

# 앞으로 만드는 모든 파일은 날짜와 시간을 주석으로 표시해 줘.
```

```
손글씨 인식 프로그램을 웹 버전과 데스크톱 버전으로 나누어 개발하고 싶어. web_version과 desktop_version 폴더를 만들고, 각 폴더에 해당하는 CLAUDE.md 파일도 생성해 줘.
```
