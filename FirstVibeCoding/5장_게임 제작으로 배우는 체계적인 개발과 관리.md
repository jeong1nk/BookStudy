## 🔖핵심 키워드
- **할루시네이션**: AI가 그럴듯하지만 틀린 정보를 생성하는 현상
- **/memory**: CLAUDE.md에 검증 가이드라인 저장/편집
- **/clear**: 대화와 컨텍스트를 완전히 초기화
- **커스텀 명령어**: 사용자가 직접 정의하는 단축 지시어
- **전역/프로젝트 명령어**: ~/.claude/commands/ vs.  .claude/commands/
- **인수/플레이스홀더**: $ARGUMENTS, $1, $2로 유연한 명령어 설계
- **명령어 체이닝**: && 연산자로 여러 명령어 순차 실행
- **통합 명령어**: 여러 작업을 하나로 묶은 자동화 파이프라인



## 5-1 할루시네이션 없는 AI 콘텐츠
### 할루시네이션(Hallucination)이란?
- AI가 그럴듯하지만 사실과 다른 정보를 진짜처럼 만들어내는 현상
- 패턴 학습 기반 생성 모델의 특성상 불확실한 정보도 확신에 찬 어조로 답변함. 그러므로 **교차 검증 가이드라인이 필수임.**
- 예) “세계에서 가장 긴 강은?”
- AI 대답: 나일강
- 문제점: 최근 연구에서 아마존 강이 더 길다는 주장도 있음
- 해결책: “전통적 측정 기준으로” 조건 추가 필요

### /memory 명령어로 가이드라인 구축
- AI가 기억하는 프로젝트 정보를 확인하고 관리, CLAUDE.md 파일을 편집
1. /memory → Project memory 선택
2. 시스템 에디터에서 CLAUDE.md  열림
3. 가이드라인 추가 후 저장 
- 예) 교차 검증 가이드라인(퀴즈 게임 기준)
  1. 역사적 사실에 연도가 있는가  
  2. 최상급 표현에 기준이 있는가?
  3. 논란의 여지가 있는 주제인가?
  4. 출처를 명시할 수 있는가?

### /clear
- 현재 세션에서 했던 대화나 작업 컨텍스트가 초기화 됨
- 새로운 가이드라인 등을 적용할 때 이전의 프롬포트에는 영향을 받지 않는 새로은 프로젝트 생성이 가능

## 5-2 자동화로 개발 효율 높이기
### 커스텀 명령어(Costom Command)란?
- 사용자가 직접 정의하는 나만의 단축  지시어
- 반복적으로 쓰는 지시사항을 명령어로 만들어두면, 매번 긴 프롬포트를 입력하지 않아도 된다.
- 반복 작업의 문제점: 문제 형식 통일 / 가이드 라인 확인 / 난이도 조정 등 매번 긴 프롬포트 → 효율 저하, 실수 증가
- 커스텀 명령어의 장점: 마크다운 파일로 정의 → 명령어 한 번으로 복잡한 작업 자동 실행

### 전역 명령어 vs 프로젝트 명령어
- 전역 명령어

```jsx
~/.claude/commands/
```

  - 홈 디렉토리에 저장(~는 홈 디렉터리를 의미)
  - 모든 프로젝트에서 공통으로 사용 가능

- 프로젝트 명령어

```jsx
.claude/commands/
```

  - 현재 프로젝트 폴더에 저장(.는 현재 디렉토리를 의미)
  - 해당 프로젝트에서만 사용 가능

### 커스텀 명령어 만들기
1. 명령어로 폴더 생성: “.claude/commands 폴더를 생성해줘”
2. 명령어로 파일 생성: 커스텀 명령어 이름의 md 파일 생성 요청
3. **클로드 코드 재시작**: /exit → claude
4. 커스텀 명령어 실행: 설정한 커스텀 명령어 이름 입력
- **커스텀 명령어 생성 후 반드시 클로드 코드 재시작 필요!**

### 인수(Argument)로 명령어 확장하기
- 인수: 명령어에 전달하는 추가 정보
- “무엇을 대상으로 어떻게 할 것인가”를 구체적으로 지정
- $ARGUMENTS, $1, $2 등 플레이스홀더 사용


## 5-3 명령어 체이닝과 유지보수 전략
### 명령어 체이닝(Command Chaining)
- 여러 커스텀 명령어를 순서대로 연결해 반복 작업을 자동화
- && 연산자로 연결하면 앞 명령 성공시 다음 명령 실행

```jsx
/커스텀 명령어1 명령 && /커스텀 명령어2 명령 ...
```

- 앞 명령 실패 시 다음 명령 실행 안 됨 → 작은 단위로 테스트 후 연결

### 통합 커스텀 명령어
- 일일 업데이트를 한 번에 처리하는 통합 명령어
- 데이터 구조  파악 → 문항 수/분포 확인 → 카테고리 결손 파악 → 중복 체크 → 새 문제 생성 → 검증 → 백업 → 리포트 출력
- 통합 명령어의 장점: 매일 해야 하는 업데이트/검증/백업/보고를 명령어 하나로 자동 수행, 각 단계마다 검증해 실패시 즉시 중단.

### AI가 스스로 만드는 커스텀 명령어
- 클로드 코드에게 필요한 명령어를 스스로  판단해  만들도록 할 수 있다.
- 예) 선생님 모드 만들기

```jsx
“선생님 모드를 만들어줘. 여러 플레이어의 퀴즈결과를 수집, 분석, 비교하고 보고서로 시각화 하는 기능이야. 필요한 커스텀 명령어를 스스로 생성하고 통합해줘” 
```

- 위 프롬포트를 실행하면 클로드가 스스로 분석해 커스텀 명령어를 자동 생성함
- 각 명령어를 독립된 .md 파일로 관리 → 필요한 부분 만 선택적 업데이트가 가능
