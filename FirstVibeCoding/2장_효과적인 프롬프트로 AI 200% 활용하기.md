## 🔖핵심 키워드
- **프롬포트**: AI에게 전달하는 요청, 명확성, 구체성, 맥락 제공
- **5W1H**: WHY, WHO, WHAT, WHEN, WHERE, HOW, 체계적 사고의 틀
- **PRD**: 제품 기획서, 바이브 코딩의 효과적인 프롬포트
- **4단계 전략**: 뼈대→기능→디자인→점검

---

## 02-1 AI를 깨우는 프롬프트의 비밀
### 프롬프트의 중요성
- AI는 방대한 언어 데이터를 학습한 지식 저장소이며, 소통할 수 있는 통로는 **프롬포트 창 하나 뿐**이다.
- 즉, **결과의 품질 = 프롬포트의 품질**
- 예) 나쁜 프롬포트

```jsx
"좋은 데로 데려다줘" -> 안내 불가
```

- 예) 좋은 프롬포트

```jsx
"서울역에서 강남역까지 가장 빠른 길" -> 정확한 안내 
```

### 좋은 프롬포트의 3가지 조건
1. **명확성**
- 모호한 표현을 피하고 원하는 결과를 구체적으로 전달
- 예) “멋진 홈페이지” → X, “시계와 날씨가 포함된 홈페이지” → O
2. **구체성**
- 필요한 기능이나 조건을 세부적으로 지시
- 예) 서울 날씨, 기술 뉴스, 상단에 시계와 검색창
3. **맥락 제공**
- 왜 필요한지, 어떤 상황에서 활용되는지 설명
- 예) 취업용 포트폴리오,  채용담당자가 볼 예정이야

### ⭐5W1H 프레임 워크
- **WHY**:  왜 만드는가?, 목적과 동기
- **WHO**: 누구를 위한 것인가? 대상 사용자
- **WHAT**: 무엇을 만들 것인가?, 핵심 기능과 내용
- **WHEN**: 언제 사용되는가?, 사용 시점과 상황
- **WHERE**: 어디서 사용되는가?, 사용 환경과 플랫폼
- **HOW**: 어떻게 만들 것인가?, 구현 방식과 기술

→ 이 질문에 답하다 보면 막연한 아이디어가 구체적인 기획으로 발전함

### ⭐PRD(Product Requirements Document, 제품기획서)
- 개발자들이 코딩 전에 작성하는 문서
- 좋은 프롬포트 = 좋은 기획서, 무엇을 만들지, 왜 필요한지, 어떻게 작동해야 하는지 정리 → 본질이 같다.
- 예) 5W1H 기반 PRD 요청 예시

```jsx
나는 프리랜서 마케터고, 취업을 위한 포트폴리오 웹사이트를 만들고 싶어.

1. 왜? 마케팅 회사 취업
2. 누가? 채용 담당자
3. 무엇을? 경력, 프로젝트 성과, 연락처
4. 언제? 이력서와 함께 제출
5. 어디서? 웹 브라우저
6. 어떻게? 반응형 웹페이지

이 내용으로 PRD를 작성해줘.
```

## 02-2 실전! 포트폴리오 웹사이트 완성하기
### 4단계 전략(뼈대 → 기능 → 디자인 → 점검)
1. **뼈대**: 기본 HTML 구조, 섹션별 고유 이름
2. **기능**: 실제 데이터 추가, 로직 구현
3. **디자인**: UI/UX 적용, 레퍼런스 활용
4. **점검**: 테스트, 품질 검수
- 각 단계마다 **요청→생성→확인→수정** 사이클 반복

1. PRD 작성

```jsx
이 PRD대로 진행할 거야. 먼저 PRD를 기반으로 HTML 문서를 작성해 줘.
섹션을 나누고, 수정을 대비해 각 섹션에 고유한 이름을 붙여 줘.
아직 기능은 구현하지 말고, 전체 구조만 보여 줘.
```

2. 뼈대(프레임) 확인

```jsx
포트폴리오 웹페이지를 만들려고 해.
주요 기능은 채용 담당자가 30초 안에 내 역량을 파악할 수 있는 임팩트 있는 구성이야.
프리랜서 전환을 준비하는 마케터를 위한 것이고,
경쟁력 있는 지원자로 보이기 위해 필요해.
어떻게 구현하면 좋을지 기술적인 방향과 함께 구체적인 PRD를 작성해 줘.
```

3. 내 정보에 맞춰 예시 프레임 작성

```jsx
나의 경력 포트폴리오는 다음과 같아. 섹션별로 다음 내용을 참고해서 업데이트해 줘.
나는 3년차, 퍼포먼스/콘텐츠 마케팅 전문가야.
- 핵심 성과: ROAS 200%, 25개 캠페인, 연 8억 매출 기여한 거고,
- 3년간 포지션 변화: 주니어(2023) → 퍼포먼스 마케터(2024) → 매니저+자문(2025)
- 스킬 레벨: 퍼포먼스 마케팅: 75%, 콘텐츠 마케팅: 70%, 데이터 분석 (GA4): 65%
다음은 나의 대표 케이스 스터디 이력이야.
- 이커머스: 월 광고비 1천만원, ROAS 200%
- 스타트업: 인스타 팔로워 2천→8천(6개월) 증가
- 로컬 브랜드: 블로그 방문자 500→3천(4개월) 증가
```

4. 디자인 바꾸기(테마를 알려주는 것이 빠르고 효과적)

```jsx
워드프레스 테마 중에서 이 포트폴리오와 가장 잘 어울리는 것을 하나 선택해서 디자인을 수정해 줘. 섹션별로 색상 톤을 달리 해서 구분이 잘 되게 해 줘.
```

5. 검토하기

```jsx
포트폴리오 웹페이지의 모든 부분이 잘 만들어졌는지 검토해 줘. PRD대로 제작되었는지, 각 링크가 문제없이 작동하는지 확인해.
```

6. 수정 사항을 반영해 업데이트 후 완성

```jsx
발견된 수정 사항대로 업데이트하고, 완벽한 프리랜서 전환용 포트폴리오를 완성해.
```
