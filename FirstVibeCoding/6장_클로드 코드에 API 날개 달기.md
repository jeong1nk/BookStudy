## 🔖핵심 키워드
- **API**: 프로그램 간 통신을 위한 다리, 통신 규칙
- **오픈 라우터**: 여러AI 모델 API를 한곳에 모은 통합 플랫폼
- **API 키**: 사용자를 인증하는 비밀 열쇠
- **.env / .gitignore**: API 키 저장 및 보안 관리 파일
- **다중 AI 모델 연동**: 이미지 인식 + 텍스트 생성 모델 함께 활용
- **PRD 단계별 개발**: 복잡한 앱을 작은 단위로 나누어 점진적 구현

---

### API(Application Programming Interface)란?
- 프로그램과 프로그램 사이를 연결하는 다리
- 간단한 요청만으로 복잡한 기능을 가져다 쓸 수 있게 해주는 통신 규칙
- 예) 클로드, CaatGPT, Gemma 등 AI 개발사들이 API로 자사 모델을 제공 → 요청 시 AI가 직접 응답하는 것처럼 결과 수신

### 오픈라우터(OpenRouter) 소개
- 여러 AI 모델 API를 한곳에 모아 제공하는 통합 플랫폼
- 모델 비교: 여러 AI 모델을 한눈에 비교 가능
- 무료/유료 필터: 무료 모델을 필터링해 쉽게 확인 가능
- 통합 API 키: 하나의 키로 다양한 모델 사용 가능
- [openrouter.ai](http://openrouter.ai)

- **제공되는 API 키는 한번만 제공되므로 절대 잃어버리면 안됨!(공유 해서도 안됨)**
내용 변경: “OPENROUTER_API_KEY=”를 키 앞에 추가
파일 이름: .env
파일 형식: 모든 파일로 변경
프로젝트 폴더에 저장해두기
- 이후 클로드 코드에 다음과 같이 명령해 키를 안전하게 사용하기

```jsx
"OpenRouter에서 받은 API 키를  .env 파일로 저장했어.  이 키를 안전하게 사용할 수 있도록 준비해줘"
```

- 그러면 다음과 같이 생성되는 파일들이 생성될 것이다.
    - .gitignore: API 키가 Git에 노출되지 않도록 보호(깃허브에 업로드 하지 않을 파일을 명시)
    - requirements.txt: 필요한 파이썬 패키지
    - main.py: OpenRouter API 사용 예제 코드

```jsx
"이제 준비된 API가 실제로 작동하는지 테스트해 줘.
이미지 인식은 google/gemma-3-27b-it:free 모델을 이용하고,
텍스트 인식은 deepseek/deepseek-chat -v3.1:free 모델을 이용할 거야.
API를 통한 텍스트와 이미지 인식을 각각 테스트해서 실행 결과를 알려줘."
```

### PRD 문서 3단계 별로 생성

```jsx
"앞서 만든 OpenRouter API를 이용해서, 냉장고 사진에서 재료를 인식하고 레시피를 추천하는 웹 애플리케이션
을 만들고 싶어. 다음과 같이 3단계로 나누어서 PRD를 만들어 줘.
1단계는 이미지를 입력받고 (모델이름) 모델을 사용해서 이미지를 인식해.
2단계는 1단계에서 얻은 정보와 (모델이름) 모델을 사용해서 레시피를 생성해.
3단계는 사용자 프로필을 만들어서 레시피를 저장해.
각 단계를 PRD_step1.md, PRD_step2.md, PRD_step3.md로 나누어 저장해 줘"
```

- 이후 단계별로 하나씩 실행해서 만들기
- 만약 중간에 확인해보고 싶으면 “메인 어플리케이션을 웹 브라우저에서 실행해서 내가 직접 n단계 결과를 테스트하게 해줘” 이렇게 입력도 가 능

### 가이드라인을 만들어 점검하기
- 클로드 코드가 제대로 기능을 구현 했는지 확인을 꼭 해야함
- CLAUDE.md의 마지막에 추가
    - OpenRouter API를 이용해서 실제 AI 모델이  이미지를 인식하고  레시피를 생성하게 해줘.
    매번 실행할 때마다 API가 정확히 작동했는지, AI 모델이 문제없이 실행되었는지를 파악하고, 문제가 있다면 어떤 문제가 있는 지를 보고해.

```jsx
## 클로드 코드 내에서 프롬포트 입력
"현재 프로젝트의 CLAUDE.md 내용을 확인해줘."
```

- 이후 추가된 지침에 따라 API 상태를 테스트하고 보고하도록 프롬포트 입력

```jsx
"지금까지 만든 앱을 방금 저장한 가이드라인을 참고해서 점검해줘. 가이드라인에 따라 정확하게 상태를 테스트해서 보고해줘."
```

- 예외 처리 관련해서도 꼭 점검하기

```jsx
"분석에 실패하면 실패했다고 정직하게 웹브라우저에 표시하게 해줘."
```
