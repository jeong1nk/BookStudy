## 01-1 나의 코딩 파트너, AI 어시스턴트
### 바이브 코딩(Vibe Coding)이란?
- 정의: AI와 대화를 주고받으며 프로그램을 만드는 개발 방식
- 기존에는 HTML, CSS, JS 등의 문법을 학습루, 직접 코드를 작성해 프로그램을 개발했다.
- 하지만 이제는 AI에게 말로 “요청” 을 하면 AI가 코드를 생성하고, 수정사항만  요청하면 된다.
- 즉, 코딩 경험이 없어도 아이디어만 있으면 프로그램을 만들 수있다.

### AI 코딩 도구의 종류
1. 모델 선택형
- 여러 AI 모델 중선택해서 사용
- 예) Cursor, Replit, Windsurf
- 단점: 도구 사용료 + AI 모델 비용 이중 지불

2. 전용 모델형
- 특정 AI 모델을 직접 설치해서 사용
- 예) Claude Code, Gemini CLI
- 장점: 모델 사용료만 지불, 로컬 파일 직접 접근 가능

### AI 어시스턴트의 발전 과정
- 뉴럴 네트워크(1940) → 딥러닝(2010) → 트랜스포머(구글)(2017) → LLM(라지 랭귀지 모델)(GPT, Claude)
- 앤트로픽(Anthropic): 오픈 AI 출신 연구진이 AI 안전성을 목표로 설립한 회사, Claude를 개발

## 01-2 AI로 나만의 첫 웹페이지 만들기
### 아티팩트(Artifacts) 기능

- 대화창과 별도로 구분되는 패널로, 실제 작동하는 결과물을 즉시 확인할 수 있는 기능
- 활용분야: 보고서 작성, 차트/그래프 생성, 웹페이지 제작, 코드 실행 및 미리보기
- 특징: 수정할 때마다 이전 버전 자동저장, 다양한 시도와 비교 가능

### 클로드 시작하기
- 클로드 홈페이지에 접속하기 (https://claude.ai/)
- 새로운 클로드 아티팩트를 추가
- 프롬포트를 입력해 내가 원하는 웹페이지 만들기
- (원활한 실습 진행을 위해서는 클로드 코드를 유료 구독 해야할 듯)
